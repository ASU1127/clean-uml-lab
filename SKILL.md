---
name: clean-uml-lab
description: Generate clean UML class or use-case diagrams from requirements or structured facts, with geometry checks and editable draw.io, SVG and PNG outputs; reflow supported class edits and opted-in reconnections from a matching Clean UML model.
---

For use-case requests, read [the use-case schema](runtime/references/usecase-model.md) and run `python usecase.py model.json -o new-output` after the same runtime installation below. Keep actors outside one system boundary; preserve every supplied actor, use case and relation. Associations have no navigation arrow; include points to the included case, extend to the extended case, and generalization to the general element. Require declared extension points for extend rather than inventing them. Side hints and columns are layout choices. Report unsupported facts before omitting any. Inspect the final PNG and reviews; exit 0 is automatic geometry/native acceptance, not human preference. Use-case draw.io editing is supported, but the class reflow/import commands below are not. Other UML diagram types remain unsupported by this product.

Use this stage product for UML class diagrams with 1–40 classifiers and up to 100 relations. It supports plain-name enumerations, association navigation arrows, distinct parallel relations, explicit imported member types, qualified classifier names, public/private classifier visibility, ordered/unordered ends and one named attribute qualifier per association end. Imports and namespaces retain their resolution records. Unknown ordering stays unknown. Qualifiers are small rectangles on their declared association end, not class attributes or ordinary labels; no qualifier type is invented. Package frames, native-language implicit defaults, type-based or multi-attribute qualifiers, wildcard/static imports, ambiguous bindings, whole-end navigation with a diamond, enum operations and enum inheritance are not implemented. Preserve unsupported facts and report the limitation.

Write the supplied facts into `model.json` using [the schema](runtime/references/model.md). For requirement-driven work, record independently extracted assertions in `requirements.json`; unknown business facts stay unknown. Preserve member order, relation direction, roles and multiplicities.

If every ordinary class candidate fails, one bounded end-clearance repair may stage composition/aggregation fan departures and, when the label solver names an infeasible unqualified association/dependency, try at most 12 complete label solves over at most 192 route alternatives. Class frames and all facts stay fixed. The final repair may increase none of crossings, contacts, shared tracks, bends, total/longest route length or canvas area relative to the original baseline. Both mechanisms are independently disabled by `--no-fan-clearance` and `--no-association-clearance` on the core and measured commands. Read `fan-clearance.json` and `internal_geometry_repairs`; an internally repaired first command is not an uncorrected first-pass result. Failures remain failures. This resilience mechanism is not evidence of better complex layout or general competitor superiority.

Runtime: Python 3.12+, Node.js 22+. From this skill directory, install pinned local dependencies with `npm ci --prefix runtime --no-audit --no-fund`. Generation needs no API key or network. Check setup with `python runtime/scripts/doctor.py`.

Run `python prototype.py model.json --requirements requirements.json -o new-output`. Omit the requirements option when no independent assertions were supplied; add `--root ID` when the main object is known. Use a new output directory. Existing dependency paths can be passed with `--sharp-module` and `--elk-module`.

The default call compares the established two-layout baseline with compact global placement and spread attachments. For disconnected enumerations it also tries plain component packing and source centering before routing; this adds no UML edge or decorative frame. If every candidate fails on a qualified diagram, one additional candidate increases layer spacing using measured qualifier and label sizes. Duplicate layout requests share a per-run cache. Candidates must pass semantic-direction, hierarchy, collision and marker/label checks. A passing baseline may be replaced only by a candidate that worsens none of six measured geometry dimensions. If the baseline fails, choose a passing candidate before comparing geometry. Labels use the actual visible qualifier terminals; routing avoids already placed qualifier rectangles. Exact label-only scene reuse and bounded path caching remain enabled. This bounded search can retain crossings and does not certify human preference.

Read `run.json`, the selected candidate's audits and `baseline/requirements-check.json`, then inspect the selected PNG at readable size. `selected_valid=false` produces exit code 2 and is a failed automatic check. Report remaining crossings or ambiguity even when it is true. Deliver `diagram.drawio`, `diagram.svg`, `diagram.png` and `index.html`. Report baseline failure, geometric tradeoffs and any extra revision separately from the first call. Native title/member edits expand their classifier and move compartment separators; qualifier rectangles use native anchors on all four class faces and remain real connector terminals. Longer edits can still collide with nearby labels or classes. Native model API checks do not certify arbitrary shrinking or full desktop GUI behavior.

After editing and saving a Clean UML draw.io file, run `python reflow.py edited.drawio --model original-output/model.json -o reflowed-output`. The companion must be the matching exported `model.json`, not the unsorted source prompt. The importer supports classifier/member, role/multiplicity, relation-label and qualifier text edits, including added member lines and compressed draw.io pages. It preserves logical identities and updates unambiguous owned-type references. Add `--allow-reconnect` to import ordinary association ends or other unqualified relation ends dragged to an existing classifier frame or text row. Read `native-edit-import.json` to confirm each changed endpoint; roles, multiplicities, markers and kind stay fixed unless their supported text is explicitly edited. A qualified end cannot be reconnected, but its opposite plain end can. Disconnected lines, new/deleted classifiers, changed kinds, markers or qualifier ownership are rejected; UML kind and inheritance-cycle checks still apply. Multiple pages require `--page ID_OR_NAME`. Reflow writes a new model, import audit and regenerated diagram into a new directory; it preserves the originals and replaces manual positions. There is no live synchronization to JSON.

For runtime ablations, `--no-marker-cache` disables exact scene reuse and `--no-path-cache` disables the sampling cache. `--no-qualifier-clearance` disables the extra measured-spacing candidate. Keep output and candidate audits identical when measuring speed.

For paired balance ablations use `--no-balanced`, `--no-component-packing` or `--no-source-centering`. `--research-intrinsic` adds text-width boxes and `--research-regions` adds region hypotheses. Count their extra work; these research hypotheses are not proven default improvements. Conservative automatic selection and successful export are not evidence of superiority over all competing tools.

The normal generation call rasterizes only the selected final SVG, once. Candidate SVG/draw.io/audit records remain available; `--candidate-previews` produces optional PNG previews after selection. This changes rendering work, not layout selection or facts.

Optional actual text-bounds review: install `puppeteer-core@25.10.0` locally or pass an existing module path, then run `node review_svg.cjs new-output/diagram.svg --model new-output/model.json --engine clean --output new-review`. An installed Chrome/Chromium/Edge and Python are required; use `--browser`, `--python` and `--puppeteer-module` for explicit paths. It also supports frozen PlantUML and Mermaid class SVGs with their complete companion model and renderer metadata. It measures the final SVG once in a separate offline browser profile and reports label/label and label/class bounds conflicts. Exit 0 is no such conflict detected, 2 is review needed, and 3 is execution failure. The profile remains in the output. This optional check does not certify pixel ink, endpoint ambiguity, business facts or human aesthetics.

For improved routing and end labels, install the optional browser measurement dependency with `npm ci --prefix refinement --no-audit --no-fund`, then run `python refinement/create_uml.py model.json -o refined-output`. It needs Node 22.12+ and installed Chrome/Chromium/Edge. Supply `--requirements` and `--root` when known, as for the core. An existing Puppeteer path can still be passed with `--puppeteer-module ABSOLUTE_MODULE_PATH`. The command generates vector candidates, preserves all class frames and facts, and tries alternative attachments with path-prefix label sampling. Crossing reduction can use at most two additional total bends and 3% total route length, with separate per-route and longest-route limits. Admission compares the routed result to the legacy original-route label score; new label domains cannot revoke an already admitted geometric improvement. Original and changed routes get separate font measurements; typography caches never cross a geometry change. Actual final measurement verifies the selected projected bounds and proximity score. Two or three offline measurements normally, at most four including fallback; searches use no browser or PNG calls. Export one final PNG. Use `--generation-dir original-output` to refine an existing complete generation into a separate directory; its prior work is reported separately.

Measured label-position domains additionally translate existing text fragments on fixed routes. They reuse the matching typography measurement, move at most 12 flagged label blocks, test at most 96 positions per block and search at most 10,000 states per pass. Endpoint samples remain within 140 px and 45% of path length. Class frames, paths, text, fonts, markers and all facts stay fixed; final actual measurement verifies the translation. Original and proposed routes each use their own measurement. This adds no browser or PNG call inside the search.

End alignment reuses the current warning score while its geometry is unchanged and skips clear label blocks whose movement cannot reduce that score. Unknown fragment/end bindings retain the complete checks. `--no-alignment-score-reuse` and `--no-affected-alignment` independently disable these optimizations. Read their evaluation counters in `run.json`; fewer evaluations do not imply the same percentage of overall generation speedup. These optimizations preserve the diagram and acceptance decisions, and do not improve layout or certify visual quality.

Read `routing.json`, `proximity-review.json` and `run.json`: a proximity warning means text is too near another relation under a fixed geometric heuristic, not a UML Property-ownership or human-preference judgment. Remaining warnings or crossings return `needs_review`; exit 0 means generation and native checks completed, not human acceptance. `--no-font-domains` disables the added position search; `--no-measured-fragments` uses nominal block geometry and `--no-dense-prefix` retains sparse endpoint samples. Existing `--no-routes`, `--no-prefix-routing`, `--no-crossing-tradeoff`, `--no-align`, `--no-refine` and `--no-cache-distances` remain available; `--no-refine` disables both label refinements. The position search is compared with the shipped label workflow and has an independently switchable geometry/sample factorial. Evidence remains partial: complex width, remaining crossings, independent skill comparisons and full native GUI usability still need improvement. The core command remains available without browser dependencies.
