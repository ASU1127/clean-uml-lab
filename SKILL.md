---
name: clean-uml-lab
description: Generate clean UML class diagrams from requirements or structured facts, with complete role and multiplicity labels, audited layout candidates, and editable draw.io, SVG and PNG outputs.
---

Use this stage product for UML class diagrams with 1–40 classifiers and up to 100 relations. It supports plain-name enumerations, association navigation arrows, distinct parallel relations, explicit imported member types, qualified classifier names, public/private classifier visibility, ordered/unordered ends and one named attribute qualifier per association end. Imports and namespaces retain their resolution records. Unknown ordering stays unknown. Qualifiers are small rectangles on their declared association end, not class attributes or ordinary labels; no qualifier type is invented. Package frames, native-language implicit defaults, type-based or multi-attribute qualifiers, wildcard/static imports, ambiguous bindings, whole-end navigation with a diamond, enum operations and enum inheritance are not implemented. Preserve unsupported facts and report the limitation.

Write the supplied facts into `model.json` using [the schema](runtime/references/model.md). For requirement-driven work, record independently extracted assertions in `requirements.json`; unknown business facts stay unknown. Preserve member order, relation direction, roles and multiplicities.

Runtime: Python 3.12+, Node.js 22+. From this skill directory, install pinned local dependencies with `npm ci --prefix runtime --no-audit --no-fund`. Generation needs no API key or network. Check setup with `python runtime/scripts/doctor.py`.

Run `python prototype.py model.json --requirements requirements.json -o new-output`. Omit the requirements option when no independent assertions were supplied; add `--root ID` when the main object is known. Use a new output directory. Existing dependency paths can be passed with `--sharp-module` and `--elk-module`.

The default call compares the established two-layout baseline with compact global placement and spread attachments. For disconnected enumerations it also tries plain component packing and source centering before routing; this adds no UML edge or decorative frame. Duplicate layout requests share a per-run cache. Candidates must pass semantic-direction, hierarchy, collision and marker/label checks. A passing baseline may be replaced only by a candidate that worsens none of six measured geometry dimensions. If the baseline fails, choose a passing candidate before comparing geometry; an invalid baseline cannot veto a valid export merely because its area is smaller. Labels are solved jointly, including qualifier rectangle clearance. Qualifiers keep a natural exit direction without adding an elbow; unsupported attachment geometry is rejected. Exact label-only scene reuse and bounded path caching remain enabled. This bounded search can retain crossings and does not certify human preference.

Read `run.json`, the selected candidate's audits and `baseline/requirements-check.json`, then inspect the selected PNG at readable size. `selected_valid=false` produces exit code 2 and is a failed automatic check. Report remaining crossings or ambiguity even when it is true. Deliver `diagram.drawio`, `diagram.svg`, `diagram.png` and `index.html`. Report baseline failure, geometric tradeoffs and any extra revision separately from the first call. Draw.io exports attach qualifiers through real rectangle terminals and preserve association ownership metadata; editing the exported file does not synchronize back to the original JSON model. Arbitrary shrinking and full desktop GUI behavior are not certified.

For runtime ablations, `--no-marker-cache` disables exact scene reuse and `--no-path-cache` disables the sampling cache. Keep output and candidate audits identical when measuring speed.

For paired balance ablations use `--no-balanced`, `--no-component-packing` or `--no-source-centering`. `--research-intrinsic` adds text-width boxes and `--research-regions` adds region hypotheses. Count their extra work; these research hypotheses are not proven default improvements. Conservative automatic selection and successful export are not evidence of superiority over all competing tools.
